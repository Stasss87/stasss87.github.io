Application information

UCC MCA Pipeline

Daily CSV and Excel delivery to an approved Google Drive folder.

What the connection does

UCC MCA Pipeline is an office application that prepares daily UCC/MCA lead delivery files. Its optional Google Drive connection uploads the accepted CSV and Excel files from the office computer to a folder selected by the Google account owner. Authorized colleagues can open the dated files there.

This is a daily file delivery, not a live spreadsheet or call-center CRM. This website provides application information only; it does not host lead files or provide access to the office program.

Access stays limited

The account owner authorizes the application in Google's browser window and selects the delivery folder through Google Picker. The application requests the limited drive.file permission for files it creates or the user selects for use with it.

It does not request unrestricted access to Google Drive, Gmail or Google Contacts, and it never asks for a Google password. The folder owner controls sharing; the application does not make the folder public or grant access to colleagues automatically.

Office operation

Delivery requires a running office computer, an authorized Google account, available storage and a network connection. Upload status must be checked before relying on a daily cloud file.

Uploading a lead does not establish that a telephone number is eligible for calling. The team's screening and calling requirements still apply.
